# Flappy Bird AI

A Flappy Bird game created using pygame and neat-python

## About

This project was originally constructed using Tech with Tim's tutorial, but was later expanded as a personal learning project

## Features

- Runs Flappy Bird 60 frames per second with scrolling backgrounds and pipes
- Can run multiple AI birds in parallel using NEAT
- Uses modified NEAT configuration to improve AI training
- Used randomized pipes and pipe gaps to make it more difficult for the AI agents

## Requirements

Make sure you have the following dependencies installed:

- python3
- pygame
- neat-python >= 2.0.0
